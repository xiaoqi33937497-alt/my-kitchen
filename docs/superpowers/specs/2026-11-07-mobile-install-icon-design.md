# 手机安装与兔子图标设计

## 目标

将现有“我的厨房”PWA 发布为无需登录即可访问的 HTTPS 网站，并把用户提供的兔子图片原样用作手机桌面图标。

## 已选方案

- 采用 HTTPS 静态托管，电脑关机后手机仍可访问。
- 网站公开访问，不增加账号或登录流程。
- 库存继续存放在手机浏览器的 IndexedDB 中，不上传到托管服务。
- 从用户提供的 600×600 PNG 等比生成 192×192、512×512 和 180×180 Apple Touch 图标；不重新绘制、不改变构图与颜色。
- PWA 名称保持“我的厨房”，主题色保持低饱和粉色。

## 不包含

- 不增加云端同步、账号体系或跨设备迁移。
- 不制作 Android APK 或 iOS 原生安装包。

## 风险与提示

- 清除浏览器网站数据可能删除本地库存，继续使用应用内备份功能。
- iOS 与 Android 的添加桌面入口不同，发布后分别提供操作步骤。

## 方案比较

- 已选：HTTPS 托管。支持正式 PWA 安装、无需电脑常开，且业务数据仍留在手机。
- 未选：局域网 HTTP。依赖电脑和同一 Wi-Fi，部分手机无法完整安装或离线使用。
- 未选：原生 APK/App。安装体验更原生，但超出本次小改动范围且维护成本更高。
