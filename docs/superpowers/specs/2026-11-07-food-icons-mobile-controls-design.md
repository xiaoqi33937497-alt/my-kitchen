# 食品图标与手机端控件优化设计

## 目的

让库存里的食品图标更符合名称，并改善手机上“手动添加”和库存筛选控件的可读性与点击体验。

## 目标

- 食品名称优先匹配对应 Emoji，例如鸡蛋显示 🥚。
- 未识别名称时按食品分类显示通用图标，避免空白。
- “＋ 手动添加”在按钮内水平、垂直居中。
- 库存页三个筛选框保持同排，但增大文字、高度和触控区域。
- 保留现有库存数据与本地存储结构。

## 不包含

- 暂不增加手动选择 Emoji 的表单。
- 不修改保质期算法、库存字段或 IndexedDB 结构。
- 不改变现有网址。

## 方案比较

1. 名称关键词优先、分类兜底：匹配准确度与操作简洁度最好，采用此方案。
2. 仅按分类匹配：实现简单，但无法解决鸡蛋显示通用蔬菜图标的问题。
3. 添加时手动选择图标：控制最精确，但增加操作步骤和数据结构改动，本次不采用。

## 实现约定

- 新增独立的食品 Emoji 匹配函数，覆盖常见蛋、肉、鱼、奶、水果、蔬菜、主食、饮品和零食关键词。
- 匹配不到名称时使用分类默认 Emoji。
- 手动添加按钮使用居中弹性布局，并单独控制加号与文字间距。
- 筛选框最小高度约 48px、文字 16px，并扩大横向间距。
- 修改完成后运行测试和生产构建，再发布到现有 GitHub Pages 地址。
